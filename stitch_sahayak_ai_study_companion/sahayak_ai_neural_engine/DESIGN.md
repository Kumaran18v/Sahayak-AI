## Brand & Style

This design system embodies the apex of local-first computational intelligence—engineered specifically for high-efficiency, Snapdragon-powered enterprise and executive study environments. The aesthetic converges deep-tech workstation precision with executive serenity. It delivers a hyper-responsive, low-latency sensory profile: completely devoid of cloud latency lag, physically rooted on-device, and private by architecture.

The core visual language leverages **Precision Dark Glassmorphism and Deep-Tech Instrumentation**. The interface behaves like high-performance avionics or specialized neural diagnostic software:
- **Canvas Environment:** Deep obsidian foundations layered with controlled micro-luminescence and directional rim illumination.
- **Surface Philosophy:** Smoked translucent panes anchored by ultra-fine, razor-etched linear borders rather than diffuse heavy dropshadows.
- **Emotional Signature:** Hyper-focused, impenetrable, instantaneous, calm under cognitive overload, and visibly accelerating through dedicated hardware.

## Colors

The color palette establishes an uncompromising on-device compute hierarchy. High-chroma accents are deployed strictly as dynamic telemetry, active neural nodes, and critical indicators, maintaining structural darkness across 90% of visual weight.

### Tonal Foundation (Substrates & Surfaces)
- **Base Canvas (`#080B11`):** Absolute ground plane; minimizes organic OLED power consumption while providing limitless contrast depth.
- **Surface Tier 1 (`#0D111A`):** Structural panels, workspaces, and navigation side rails.
- **Surface Tier 2 (`#121826`):** Floating modular cards, inspector flyouts, and contextual decks.
- **Surface Tier 3 / Glass Tint (`rgba(18, 24, 38, 0.72)`): Dynamic backdrop-filtered overlays with frosted attenuation.

### Kinetic Accents & Energy Bands
- **Primary / Neural Acceleration (`#00D2FF`):** Snapdragon NPU processing pipelines, active context retrieval, and primary focus indicators.
- **Secondary / Deep Synthesis (`#6366F1`):** Latent semantic structures, high-dimensional vector embeddings, and cross-source synthesis matrices.
- **Tertiary / Core Insight & Attention (`#F59E0B`):** Human-in-the-loop overrides, critical synthesis milestones, bookmarks, and hardware thermal/thermal-safe throttling metrics.

### System Borders & Radiance
- **Micro-Borders:** Linear alpha definitions using `rgba(255, 255, 255, 0.08)` across standard perimeters, intensifying to `rgba(0, 210, 255, 0.35)` on focus or real-time computation states.
- **Text Tones:** Primary copy at `#F8FAFC` (Slate 50), secondary metadata at `#94A3B8` (Slate 400), and disabled/trace labels at `#475569` (Slate 600).

## Typography

The typographic hierarchy enforces strict domain boundaries between conversational cognition, body study materials, and bare-metal runtime telemetry.

- **Plus Jakarta Sans (Headings & Synthesis Titles):** Provides modern architectural authority with clean geometric aperture geometry, avoiding cold rigidity while remaining distinctly computational.
- **Inter (Explanatory & Conversational Corpus):** Serves as the cognitive baseline. Tuned specifically for sustained academic intake, dense analytical passages, and high-legibility document decomposition.
- **JetBrains Mono (Telemetry, Performance Indices & Specs):** Handles token generation rates (tokens/sec), NPU TOPS allocations, hardware temperatures, memory footprints, and contextual citation indices. All numerical readouts must adopt tabular figures (`tnum`) to eliminate spatial jitter during active inference.

## Layout & Spacing

The spatial architecture runs on a strict **8px modular grid** designed for dense multi-pane workstation environments.

### Grid Architecture
- **Desktop/Workstation (12-Column Fluid):** 16px (`1rem`) minimum gutters transitioning to 24px (`1.5rem`) on high-resolution displays (>1440px). Side docks and inspector modules adopt standard widths (e.g., 320px telemetry pane, 72px collapsed toolbelt).
- **Reflow Logic:** Multi-column document + reasoning panes degrade gracefully into split vertical splitters on convertible tablet formats and single-column stacked workflows on mobile viewports.
- **Rhythm & Gaps:** All spatial intervals between adjacent widgets, analytical clusters, and control groups adhere to tokens `space-xs` through `space-2xl`. No arbitrary margins or uneven paddings are permitted.

## Elevation & Depth

Visual hierarchy does not use soft natural lighting; instead, it is constructed through **layered dark transmittance, backdrop occlusion, and edge luminescence**.

1. **Level 0 (Root Slate):** `#080B11`. Solid canvas. Employs a low-intensity, static radial glow (`radial-gradient(ellipse at 50% 0%, rgba(0, 210, 255, 0.04), transparent 70%)`) to create environmental depth.
2. **Level 1 (Docked Containers):** `#0D111A` with a 1px border of `rgba(255, 255, 255, 0.06)`. Flat surface elevation with zero drop shadow.
3. **Level 2 (Floating Cards & Context Workspaces):** Background `rgba(18, 24, 38, 0.85)` with `backdrop-filter: blur(16px)`. Border is 1px `rgba(255, 255, 255, 0.09)`. Subtle shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.6)`.
4. **Level 3 (Modal Dialogs & Active Nodes):** Background `rgba(22, 30, 48, 0.95)` with `backdrop-filter: blur(24px)`. Rim-lit using `rgba(0, 210, 255, 0.2)` along the top edge, grounded by an ambient cast shadow: `0 20px 48px -8px rgba(0, 0, 0, 0.8), 0 0 1px 1px rgba(255, 255, 255, 0.1)`.
5. **Dynamic Processing Glow:** During active on-chip NPU inference, panels display an internal pulse effect using an animated box-shadow: `inset 0 0 12px rgba(0, 210, 255, 0.12)`.

## Shapes

The design uses balanced, rounded corners that smooth out complex data environments while keeping the layout sharp and precise.

- **Primary Cards & Workspaces (`rounded-lg` / 1rem - 16px):** Canonical shape for research decks, query consoles, and interactive PDF/code viewers.
- **Inspectors & Flyout Panels (`rounded-xl` / 1.5rem - 24px):** Used along outer container boundaries to visually encapsulate large tool sets.
- **Interactive Controls, Inputs & Inner Tiles (`rounded` / 0.5rem - 8px):** Applied to buttons, form fields, telemetry cells, and segmented control chips.
- **Pill Badges (`rounded-full`):** Reserved exclusively for live status chips, execution modes (e.g., "LOCAL NPU ACTIVE"), and category tag markers.

## Components

### 1. Buttons
- **Primary Action (Hardware Compute):** Gradient fill from `#00D2FF` to `#00A3FF`, high-contrast dark text (`#080B11`), `fontWeight: 600`. Hover state triggers an external cyan halo (`0 0 16px rgba(0, 210, 255, 0.4)`).
- **Secondary Action (Substrate):** Background `rgba(255, 255, 255, 0.04)`, 1px border `rgba(255, 255, 255, 0.08)`, text `#F8FAFC`. On hover, background shifts to `rgba(255, 255, 255, 0.08)` and border brightens to `rgba(255, 255, 255, 0.2)`.
- **Ghost/Tertiary:** No background or border. Text `#94A3B8`, shifting to `#00D2FF` on hover.

### 2. Pill Badges & Telemetry Chips
- Height: 24px. Padding: 0 10px. Rounded-full.
- Background: `rgba(0, 210, 255, 0.08)`. Border: 1px `rgba(0, 210, 255, 0.2)`.
- Typographic style: `label-caps`.
- **Pulsing Dot:** 6px circle with a ping animation (`#00D2FF`) for active compute, or steady amber (`#F59E0B`) for low-power or thermal monitoring states.

### 3. Segmented Controls
- Encapsulated pill shell (`#080B11`) with 4px inner padding.
- Segment items use `rounded` (6px) geometry. Active segment features a high-density glass background (`#1A2234`) with a 1px `rgba(255, 255, 255, 0.12)` border and bright contrast label.

### 4. Input Fields & Query Console
- Background: `rgba(13, 17, 26, 0.8)`. Border: 1px `rgba(255, 255, 255, 0.08)`. Height: 44px (Standard) or 56px (Neural Query Dock).
- Focus state: Border instantly shifts to `#00D2FF` with a soft spread ring (`0 0 0 2px rgba(0, 210, 255, 0.2)`). JetBrains Mono watermark icon for keyboard shortcuts (e.g., `⌘K`).

### 5. Cards & Decks
- Base fill `#0D111A` with a 1px border of `rgba(255, 255, 255, 0.08)`. Internal padding: `space-lg` (24px).
- Optional header separation via an interior linear gradient line (`linear-gradient(90deg, rgba(255,255,255,0.08), transparent)`).

### 6. Interactive Knowledge Graph Nodes
- **Unselected:** Circular node (diameter: 28px), background `#121826`, border 1.5px `#6366F1`.
- **Selected/Active:** Scaled to 34px, background `#6366F1`, outer glow `0 0 20px rgba(99, 102, 241, 0.6)`. Interconnecting vectors drawn with 1px animated dashed cyan paths (`rgba(0, 210, 255, 0.4)`).

### 7. Telemetry Sparks & Diagnostic Gauges
- Integrated inline real-time charts. Height: 32px.
- Stroke: 1.5px solid `#00D2FF`. Fill: Vertical gradient fading from `rgba(0, 210, 255, 0.25)` to `transparent`.
- Always paired with `mono-telemetry-sm` annotations indicating latency (e.g., `4.2ms`) and context size allocations.
